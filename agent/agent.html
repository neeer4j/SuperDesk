📖 How to Use SuperDesk
🖥️ Share Your Screen (Host)
1. Sign in with your email and OTP code
2. Click "Share Screen" in the sidebar
3. Click "Start Sharing" and select a screen/window
4. Share the 8-character Session ID with the person who wants to view/control your screen
🔗 Join a Session (Guest)
1. Get the Session ID from the host
2. Click "Join Session" in the sidebar
3. Enter the Session ID and click "Connect"
4. Use the control buttons to enable mouse/keyboard control or fullscreen
📁 Transfer Files
Host: Drag & drop files into the File Transfer area while sharing
Guest: Accept incoming files via the popup prompt, then choose where to save
💡 Tip: Both host and guest must be using the SuperDesk desktop app for file transfer to work. Remote control requires the host to enable it.
